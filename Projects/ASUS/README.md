# ASUS projects

This directory contains ASUS drivers and utilities. Device-specific firmware
profiles remain explicitly identified. Start with the [repository guide](../../README.md)
before installing any project.

| Project | Status | Purpose |
| :--- | :--- | :--- |
| [ASUS Control](AsusControl) | 1.1.2 · policy/UI validation pending | Device settings pane for fans, battery care and input controls, with matching AsusSMC source. |
| [X1605VA Assistant](X1605VAAssistant) | Deprecated | Menu-bar controls and ACPI support for microphone, keyboard backlight, trackpad, and brightness. |
| [AsusX1605VATouchpadDxe](AsusX1605VATouchpadDxe) | Beta | Touchpad pointer support in the OpenCore picker. |
