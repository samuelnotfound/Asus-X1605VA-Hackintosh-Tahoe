# X1605VA projects

This directory contains hardware-specific drivers and utilities for the
ASUS Vivobook X1605VA. Start with the [repository guide](../../README.md)
before installing any project.

| Project | Status | Purpose |
| :--- | :--- | :--- |
| [X1605VA Assistant](X1605VAAssistant) | Deprecated | Menu-bar controls and ACPI support for microphone, keyboard backlight, trackpad, and brightness. |
| [AsusX1605VATouchpadDxe](AsusX1605VATouchpadDxe) | Beta | Touchpad pointer support in the OpenCore picker. |
